## Next-Iteration Hypothesis

The next iteration should target artifact samples that still look readable or structure-like: add more hard negatives and real/semi-real examples for `ocr_garbage`, `skip`, and `boilerplate`, plus a smaller cleanup pass on `jsonl` and `json`. That combination should keep the artifact recall gains, recover code recall, and chip away at the `structured_artifact` boundary failure mode instead of only improving validation metrics.

This convergence pass was an eval-only refresh using the existing trained artifacts already present in `training/output/`. The top-line numbers above came from `task -d training train:eval-onnx`, and the per-sample predictions plus slice reports came from `task -d training train:eval-slices`.
