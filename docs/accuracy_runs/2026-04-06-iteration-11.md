## Analysis

**Clear eval held steady** at 93.0% — the relabeling didn't degrade unambiguous classification. The -0.4% is within noise.

**Boundary improved 3 points** from 37.2% → 40.2%. The `unknown → skip` drain is eliminated. However, boundary accuracy is still 19 points below the 59.6% target. The main remaining issue is **structured↔prose confusion** (510 structured samples misclassified as prose), which is a pre-existing problem unrelated to the unknown relabeling.

## Root Cause of Remaining Boundary Gap

The boundary eval set was generated before `c_cpp` and `objc` existed — there are no boundary test cases for these new sub-types. The structured↔prose boundary confusion (510 + 343 = 853 misclassifications) accounts for most of the gap and needs separate work (e.g., boundary-specific training data, feature engineering for structured detection).
