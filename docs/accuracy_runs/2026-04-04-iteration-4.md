## What Changed

1. **Removed artifact category**: TextCategory simplified from 5 to 3 variants (Prose, Code, Structured). Skip retained for Tier 1 short-circuits only.
2. **Reclassified artifact training data**: 33,214 artifact/skip samples reclassified by content using feature-based heuristic (→ 13,827 prose, 18,074 structured, 1,313 code).
3. **Reclassified eval sets**: 2,501 artifact samples in eval sets relabeled using the same heuristic.
4. **3-category model**: ONNX model now outputs 3 category logits instead of 5.
