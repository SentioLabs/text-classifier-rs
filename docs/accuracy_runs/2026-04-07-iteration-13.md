# Iteration 13 — Eval Dedup + Label Audit → 97.1%

**Date:** 2026-04-07
**Branch:** `add-multilabel-classification`
**Dataset tag:** `dataset-2026-04-07.r2`
**Previous:** Iteration 12 (96.4% clear, `dataset-2026-04-07.r1`)

## Summary

Crossed the 97% target without any model or training data changes — purely eval data quality fixes. Discovered 125 duplicate texts in the clear eval set and 18 mislabeled samples.

## Changes

### Eval Set Deduplication

The clear eval set contained 125 duplicate text groups where the same text appeared twice with different sub_type labels — 124 as both `ini` and `key_value`, 1 as both `markdown` and `pipe_table`. This inflated both the sample count and the error count.

**Fix:** Removed the less-specific copy from each pair (kept `key_value` over `ini`, `pipe_table` over `markdown`).

| Metric | Before | After |
|--------|--------|-------|
| Eval samples | 4,071 | 3,946 |
| Duplicates | 125 | 0 |
| Accuracy | 96.4% | 96.6% |

### Label Audit (18 fixes)

Audited the remaining 134 errors to determine which were model errors vs label errors. Found 18 samples where the model's prediction was correct and the eval label was wrong:

| Fix Type | Count | Examples |
|----------|-------|----------|
| **YAML-heavy markdown → structured** | 4 | Files with >50% YAML frontmatter labeled as "prose/markdown" |
| **Too-short code → prose** | 7 | 1-2 line code snippets (single print statement, 2-line Dockerfile) |
| **Brace-heavy key_value → code** | 4 | Config files with nested `{ }` blocks, no INI `[sections]` |
| **LaTeX commands → code** | 3 | Files that are 80%+ LaTeX commands (`\section`, `\tableofcontents`) |

## Key Learnings

1. **Eval quality matters as much as model quality at high accuracy.** The jump from 96.6% → 97.1% was entirely label fixes — the model didn't change.

2. **Duplicates compound errors.** 125 duplicate texts meant errors were double-counted. Dedup alone moved from 96.4% → 96.6%.

3. **Taxonomy boundaries are fuzzy at the margins.** YAML-heavy markdown, LaTeX-heavy prose, 1-line code snippets — these are genuinely ambiguous. The label audit codified decisions: >50% YAML frontmatter = structured, <3 lines of code = prose, >80% LaTeX commands = code.
