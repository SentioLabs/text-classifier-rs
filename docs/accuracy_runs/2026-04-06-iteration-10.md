# Iteration 10: Data Cleanup & Retrain from Clean Golden Dataset

**Date:** 2026-04-06
**Branch:** `add-multilabel-classification`

## Overview

Data cleanup iteration -- archived 16 stale files containing dirty synthetic data, renamed the clean `golden_train_audit.parquet` (123K rows, 0 synthetic) to `golden.parquet`, and retrained from clean data. Clear eval accuracy fully recovered to the iteration 8 baseline.

## Root Cause

Iteration 9 trained from `golden_raw.parquet` (136K rows, 49K synthetic) instead of the clean `golden_train_audit.parquet` (123K rows, 0 synthetic). The clean file was produced by iteration 7's label cleanup but a stale file was used for training, polluting the model with synthetic data that degraded accuracy.

## Key Findings

1. **Clear eval fully recovered to iter 8 baseline (93.4%).** This confirms that data quality -- not architecture or hyperparameters -- was the root cause of iteration 9's regression.

2. **Boundary accuracy still poor (37.2%).** The boundary eval shows massive misclassification into the `skip` category:
   - 453 code samples predicted as skip
   - 261 structured samples predicted as skip
   - 229 prose samples predicted as skip

3. **Known sub-type gaps from synthetic data removal.** The following sub-types were 100% synthetic and are now absent from training data:
   - `pipe_table` -- 0 training rows
   - `fixed_width` -- 0 training rows
   - `sgml` -- 0 training rows
